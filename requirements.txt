# Global Firefight - Drone Command Requirements

## System Requirements

### Development Environment
- Unity 2023.x LTS or later
- Visual Studio 2022 or Rider IDE
- .NET Framework 4.7.1 or later
- Git for version control

### Unity Packages Required
- Universal Render Pipeline (URP)
- Cesium for Unity (latest version)
- Input System (new Unity Input System)
- TextMeshPro
- ProBuilder (for rapid prototyping)

## External API Requirements

### NASA APIs
1. **NASA FIRMS API**
   - Purpose: Real-time wildfire data
   - Authentication: NASA Earthdata Login API key
   - Registration: https://firms.modaps.eosdis.nasa.gov/web-services/
   - Rate Limits: Standard with API key (avoid DEMO_KEY for production)

2. **NASA EONET API**
   - Purpose: Major wildfire event tracking
   - Authentication: None required (public API)
   - Endpoint: https://eonet.gsfc.nasa.gov/api/v3/events

### Google Cloud Platform
1. **Google Maps Platform**
   - Purpose: Photorealistic 3D tiles for tactical view
   - Authentication: Google Cloud API key
   - Required Services: Map Tiles API
   - Billing: Required (pay-per-use)
   - Setup: https://console.cloud.google.com/

## API Rate Limits and Quotas

### NASA FIRMS
- Standard: 10,000 requests per day
- Burst: 10 requests per second
- Data freshness: 3-hour delay for near real-time

### NASA EONET
- No published rate limits (public API)
- Recommended: Cache results, update every 6-12 hours

### Google Maps Platform
- Map Tiles API: $7.00 per 1,000 requests
- Free tier: $200 monthly credit
- Rate limit: 30,000 requests per minute

## Performance Targets

### Frame Rate
- PC Target: 60 FPS @ 1080p, 30 FPS @ 4K
- WebGL Target: 30 FPS @ 1080p

### Memory Usage
- PC: Maximum 4GB RAM usage
- WebGL: Maximum 1GB RAM usage
- Streaming: Maximum 100MB per tile load

### Network Usage
- Initial load: <500MB for base assets
- Ongoing: <10MB per hour for API updates
- Tile streaming: Variable based on movement

## Security Requirements

### API Key Management
- Store API keys in Unity's PlayerPrefs or external config
- Never commit API keys to version control
- Use environment variables for development
- Implement key rotation capabilities

### Data Privacy
- No storage of personal user data
- Temporary caching of public NASA data only
- Comply with NASA's data usage policies
- Attribution requirements for Google data
